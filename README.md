Student Problem Prediction System

About the Project

A Python-based project that analyzes student performance and identifies potential academic problems using Numerical Analysis techniques.

Technologies Used

- Python
- Tkinter
- Matplotlib
- CSV

Numerical Methods Used

- Newton Interpolation
- Lagrange Interpolation
- Gaussian Elimination
- Trapezoidal Rule

Features

- Student details input
- Academic problem identification
- Performance graph visualization
- Save student records in CSV
- Reset student details

How to Run

1. Install Python.
2. Install Matplotlib:
   "python -m pip install matplotlib"
3. Run the application:
   "python gui.py"

Project Type

Group Project – Numerical Analysis with Python
